# SkillForge

SkillForge is a production-grade, AI-powered E-Learning Platform built using enterprise microservices architecture.

## Technology Stack

### Frontend
- React 19
- Vite
- Tailwind CSS
- Axios
- React Hook Form
- Recharts
- Framer Motion

### Java
- Java 17
- Spring Boot
- Spring Cloud Gateway
- Eureka
- Spring Security
- JWT
- Spring Data JPA
- MySQL

### Python
- FastAPI
- SQLAlchemy
- MySQL
- LLM provider integrations

### .NET
- ASP.NET Core 8
- Entity Framework Core
- SignalR
- MySQL
- Razorpay

### Infrastructure
- Docker
- Docker Compose
- GitHub Actions
- Nginx
- Health checks and observability
